# hs-portfolio

Novo portfólio pessoal. React + Vite + Tailwind. PT / EN.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Motion (animações leves)

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Estrutura

```
src/
  components/   layout, sections, ui
  content/      projetos, carreira, skills, recomendações
  i18n/         PT / EN
  lib/          helpers
```

Conteúdo fica em `src/content`. Textos de interface em `src/i18n/messages.ts`.
